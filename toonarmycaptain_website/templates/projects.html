Some projects I am working on/maintain:

This website
This website, originally deployed on pythonanywhere, incorporating contact form and db One of my first projects learning flask testing, db in a webapp, automated email, responsive HTML/CSS.

dionysus - Student avatar score chart generator
App for teachers to chart test scores using ‘secret’ avatars rather than student names, for privacy purposes.
Learned to set up and integrate CI pipelines, coverage, code quality tools, implement effective versioning, JSON, argparse, OOP, basic Tkinter GUI elements, converted from unittest to pytest.
Originally implemented in fully functional paradigm, then incremental conversion to OOP, using an abstracted database to support varied db backend implementations (eg JSON files, SQLite).

xkcd_archiver - Download and maintain an archive of xkcd comics
Twist on typical web scraping starter project to quickly archive all of the images from the XKCD web comic, using the site’s JSON API and threading to download images directly rather than scraping HTML.
Learned to use requests, Flask-WTF forms, parse JSON, effectively employ threading. Iterated on over the years to improve threading, save with image metadata, add a TUI.

ixl search - improvement over IXL's built-in search
My wife was having trouble finding resources via IXL's search, so I built a (hopefully!) better search tool.
I used RapidFuzz with a custom (in-progress) synonym map, to more effectively search their sitemap/index pages, cross-referenced against curricula/standards, and scopable to grade/subject and state/standard.

pushbullet-calend - scheduled texts from calendar entries
A relative needed reminding for events, and similarly I was forgetting to text, so I automated things.
Created a simple DSL to put in Google calendar descriptions, and a daemon that polls the calendar and utilises Pushbullet to send text messages.
Extended using similar APIs to send me a text when I receive an email matching specific criteria, run with systemd.
